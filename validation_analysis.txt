## Root Cause Analysis

### Why Fixes Didn't Work Completely?

**Issue 1: Device Move Code Not Working**

The error persists:
```
RuntimeError: Expected all tensors to be on the same device,
but found at least two devices, cuda:0 and cpu!
```

**Possible Causes:**
1. Model moved back to CUDA, but data tensors still on CPU
2. LocalClusterMixture device handling issue
3. Aggregation phase mixing devices before move completes
4. The `.to(device)` call failed silently

**Issue 2: Multipliers Not Applied to Vertical**

Law school V: 31s runtime (should be ~120s with 4× multiplier)

**Evidence:**
- eval1: 30.6s
- eval2: 31.4s
- No change!

**Possible Cause:**
- Mode-specific adjustments code path not reached
- Conditional logic error
- Experiments ran with old code (before latest changes)
